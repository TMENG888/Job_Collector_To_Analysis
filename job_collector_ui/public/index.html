QUICK GUIDE

使用与安全

  1. 创建任务填写岗位关键词、城市与渠道，目标数量可留空。采集中已入库数据可随时用于洞察，无需导出。
  2. HTTP 采集使用已核验 JSON 接口或公共招聘网内嵌数据，不启动浏览器、不执行网页脚本；访问受限立即停止冷却。
  3. 开始或分步运行“全部运行”依次采集、合并、导出；也可单独运行已验证的公开接口。
  4. 暂停与续爬暂停后再次运行同一阶段即可续爬。当前未落盘的小段可能重采，最终会自动去重。
  5. 合并结果“合并去重”读取任务目录及附加目录中的标准化 CSV，以“平台 + 岗位ID”去重并做相关度排序。
账号保护原则

智联和鱼泡分别限制为单一采集进程；验证码和鱼泡滑块只由人工处理；低频随机间隔，不导出 Cookie/令牌，不伪造设备指纹。鱼泡更容易触发验证，出现验证页时请暂停并重新人工验证。
