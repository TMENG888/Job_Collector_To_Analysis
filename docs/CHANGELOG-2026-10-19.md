# 0.2.0 · 2026-10-19

本版同步本机截至 2026-10-19 的 Web、采集、知识库、助手、监督分类、浏览器扩展和 Electron 桌面原型代码。源码上传不触发生产服务重启，不迁移或删除现有数据。

## 主要更新

- 采集任务按关键词、城市及渠道安全分页预算运行，兼容历史目标条数迁移；采集中间数据可直接分析。
- 查询条件按本轮意图更新；销售相关关键词扩展、采集配置更新和确认授权绑定当前任务。
- 岗位洞察改为监督分类路径：固定发布模型或当前数据集手动启用的候选模型；无可用模型时停止，不回退纯规则筛选。
- Qwen 标注、TF-IDF＋逻辑回归训练、代理评测与人工核验、费用/Token 展示；发布版使用自己的 Base URL、API Key 和私有数据目录。
- 岗位洞察重新组织布局，减少说明性标签与冗余表单；助手工具执行流式显示、完成后折叠。
- 普通浏览器＋MV3 扩展，包含配对、岗位读取、简历匹配及确认后的有界求职流程。
- Electron 44.9.0 桌面原型：WebContentsView 原生招聘网页、独立会话、安全隔离、统一导航及启动入口修复。
- 旧平台登录和 AI 标注独立导航移除，兼容模块与历史测试不代表旧入口仍可用。

## 发布差异

发布副本不改变生产目录。只把个人硬编码路径改为项目相对路径或显式环境变量；Qwen 专属域名改为供应商通用默认地址和 JOB_INSIGHT_QWEN_BASE_URL；训练 Python 支持 JOB_INSIGHT_PYTHON。可选表格依赖继续延迟加载，原生数据库分析无需该组件。

包含固定的 4 个监督推理模型及注册清单，逐文件 SHA256 校验；不含原始样本、私有候选模型、密钥、简历、会话、任务/岗位数据库、登录态、虚拟环境和二进制运行时。销售等本机候选模型需在使用者自己的数据与 API 配置下重新训练启用。

## 验证边界

本次发布在隔离目录中检查。测试不访问真实招聘平台、不发送沟通、不投递简历、不调用付费标注、不重启生产服务。

- 256 个 JavaScript/Node 源文件语法检查通过。
- 隔离启动主服务，首页、洞察、浏览器、任务、洞察状态及分类器状态共 6 个页面/API 均返回 200。
- 桌面策略测试 5/5 通过；包含导航同步、域名限制、私网隔离及视口布局。
- 新增的合成监督分类检查通过：4 个固定模型校验及推理、正文不足待复核、外部标签不改变结果、未知岗位不回退规则、无付费调用。
- 简历匹配合成测试通过：学历、届次、经验约束、ReAct/React 区分、原始薪资及隐私字段约束。
- 历史默认回归套件 **29/35** 通过，**6 项未通过**。本次上传不宣称回归全绿。

回归入口改为汇总全部失败并返回非零，不再在首个失败处退出；包含私有样本的历史测试仍需显式 JOB_TEST_PRIVATE_FIXTURES=1，不上传私有夹具。测试输出只留在本机，不包含在 Git 提交中。

桌面此前完成 12 项本机只读布局检查；扩展的隔离集成曾通过一轮，但后续完整重跑出现显示表面不可用、页面 visibility=hidden，原生点击未完成复验。本版不把它称为所有实网交互验收通过。BOSS 等站点也可能拒绝 Electron，普通浏览器扩展仍为独立方案。

目前提供桌面源码及脚本入口，不提供独立 EXE 安装包，也没有把 Web 扩展的自动沟通/截图发送完整迁移至 Electron。历史图文说明按原样保留，旧配置与旧截图不作为当前验收结论。
