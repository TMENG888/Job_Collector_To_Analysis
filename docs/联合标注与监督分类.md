# 联合标注与监督分类

一次 Qwen 请求同时返回岗位类别、技术技能、工作职责、业务方向和公司行业。界面的“查看 AI 标签”可查看四类语义摘要；背景岗位仅用于分类训练，不混入当前数据集词云。

## 标签如何使用

- 岗位类别 include / exclude 是逻辑回归的监督目标；review 不进入训练。
- 技术、职责等语义标签用于抽样能力画像与词云，必须有模型输入中的原文证据。
- 分类器训练特征来自真实岗位标题和 JD。新版候选输入可保留任职要求及技术信息，不把仅训练样本具备的 AI 标签拼进特征，以免真实岗位分类时缺少同样输入。
- 全量分析先用合格监督分类器筛选全部岗位，再与已标注语义样本按内容关联。词云只代表语义标签覆盖的岗位，不把抽样词频外推为全库词频。

## 分类验收与语义发布分别处理

新候选未通过验收不会替换现有合格分类器。只要当前岗位已有合格分类器，保存的语义结果仍可关联该分类器，不要求语义任务与分类器来自同一轮。若当前岗位没有合格分类器，标签可查看，但不能绕过验收进行全量分析。

联合标注中的分类证据来自职责片段，语义标签证据来自原文片段，两者编号空间分别校验。已独立验证的分类结论不会因为其编号未出现在语义证据列表中而被错误降级；每个技术标签仍必须匹配原文语义证据，不能借分类证据授权任意标签。

历史结果可用已保存响应重新校验和发布，不重复请求模型。重新发布不改变原类别标签、训练数据、历史评测或用量。

## 训练与评测

公司、同文及近重复岗位必须隔离。训练集建立 TF-IDF 词表并拟合逻辑回归；仅用验证集选择预先限定的输入版本、正则化、类别权重和阈值。测试集在选择冻结后评测，不参与选择；历史测试已被查看时，对照结果不能宣传为新的独立验证。

精确率与召回率等验收条件不降低。未达标候选不启用。模型标签代理指标不是人工准确率；仍需要独立人工核验及新的边界样本。

定向补标先固定样本和训练／验证／新测试分组，再调用模型。旧测试标签不回流训练或参数选择；旧训练、验证标签可复用。筛选模型的分数只用于抽样分层，不视为真值。训练输入支持 `fixed_splits`，缺失、重复 ID 或公司／近重复跨组时拒绝训练；`grouping_samples` 固定去重语料，避免 review 数量改变去重表示。模型词表仍仅在训练集建立。新旧模型只在同一批新测试样本上对照，不直接比较不同抽样批次的指标。

新版输入契约候选通过验收后，若运行中的后台尚未加载该契约，候选须保持待启用；不把文件落盘等同于生产模型已切换，也不为加载模型中断正在运行的采集。

页面只保留顶部“生成全量分析”按钮。修改语义标签或分类器后，该按钮重新生成报告；刷新页面本身不会自动重跑分析、标注或产生模型费用。
