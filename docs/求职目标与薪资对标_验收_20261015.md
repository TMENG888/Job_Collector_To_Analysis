# 求职目标与薪资对标验收 · 2026-10-15

## 实现范围

- 独立求职目标随加密会话保存；当前明确阶段覆盖历史和简历实习意向。
- 同条件全量资格筛选、原始日／时／月／年薪分组、薪数分布、稀疏样本保护及谈判锚点。
- 报价预检：检索 → 薪资对标 → JD补查 → 模型回答；允许无工具澄清，模型失败有可读证据摘要。
- UI沿用原配色，显示求职目标、原始薪资分组、薪数和工具执行来源。

## 验证结果

专项测试 `work/test_job_salary_benchmark.mjs` 通过：实习转秋招、简历意向覆盖、届次／城市／学历资格门槛、全量样本而非前8条、单位不混算、薪数未知不补12薪、少于5条不发分位数、模型预检、认证失败兜底、无工具澄清、跨重启继续补充目标。全部使用合成样本，无真实采集。

既有回归通过：chat、resume_job_fit、sessions、http、decision_assistant、collection、resume、credentials，共8个测试脚本，另有专项测试；会话实际Windows DPAPI加密、采集确认边界和简历隐私检查保持通过。

只读真实知识库：revision 292，纳入24449条。使用合成求职画像“2027届本科，北京，智能体秋招”复现原问题；不使用或保存个人简历，不写入测试会话。

DeepSeek实测一次请求返回HTTP 200、finish_reason=stop，执行模型回答而非兜底；3步系统预检。该测试组同条件筛选36条，明确匹配届次13条，原始月薪7条、日薪1条；日薪不进入月薪。月薪报价中点中位数16K，25%–75%为15K—18K；13薪4条、15薪1条、薪数未公开2条。以上仅为指定测试条件的数据库快照，不是用户个人报价结论或当前仍在招证明。

浏览器隔离验收：目标条件条、三步系统预检、独立月薪／年包样本、未公开薪数和稀疏提示正常显示；保留复制、编辑和Markdown回答功能。隔离样本与生产数据库分开。

## 限制

部署状态：用户明确允许重启后，确认采集、打标、洞察与助手请求均空闲，已重启主服务8788与兼容助手8791。两个 `/api/assistant/context` 均返回 `assistant_flow_version:3`、24449条可检索岗位，以及 career_goal、salary_benchmark、job_details、clarification 能力。已保存的DeepSeek配置仍可读取，启动错误日志为空，未启动真实采集。刷新页面后启用新版；内存简历已随重启清空，需要重新上传。

仍为规则资格筛选、关键词检索及招聘报价描述统计，不是语义能力评测、因果模型或个人薪资预测。原文缺届次、薪资或城市会降低样本量；不以其他条件补数。跨平台同岗与过期职位仍需人工核查。简历原文只存内存，重启后需重新上传；历史会话和最小目标事实保留。
