# FastAPI 后端与兼容执行进程

对外入口改为 FastAPI，默认仍为 `http://127.0.0.1:8788`，前端地址和已有数据库路径保持一致。迁移复用既有业务模块，未将全部 JavaScript 业务逻辑重写为 Python。

## 职责分配

| 组件 | 负责内容 |
| --- | --- |
| FastAPI | 公共 HTTP 入口、训练和分析参数校验、报告读取与压缩缓存、操作去重、持久化计算队列、进程生命周期 |
| 受控 Node.js 执行进程 | 既有采集、登录会话、付费标注、训练工作流、岗位助手、兼容接口 |
| 独立计算进程 | 岗位分类器训练、面经准备和训练、全库聚类、岗位分析 |

Node.js 执行进程只绑定本机随机端口，请求须带启动时生成的内部凭据。内部计算接口同样需要凭据，不向前端公开。公共入口只接受本机工作台来源。同一数据目录通过归属锁阻止重复加载业务进程。

计算队列并发为 1，避免训练、聚类和全库分析同时抢占内存。采集网络任务和助手请求仍由兼容业务模块按原限制运行，无须等待计算队列。已有爬虫的登录、Cookie、断点和数据文件不迁移。后台启动不会自动开启采集，也不会自动调用付费模型。

## 安装与启动

要求 Node.js 可用，以及 Python 3.11 或更新版本。分类器继续使用项目原有的 `work/role_screening_env` 训练环境；API 环境不重复安装训练模型。

首次在项目根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File job_collector_ui/backend/start.ps1 -Install
```

日常双击 `启动岗位采集控制台.bat`，或运行：

```powershell
powershell -ExecutionPolicy Bypass -File job_collector_ui/backend/start.ps1
```

安装器默认把 API 虚拟环境、依赖缓存和运行文件放到 `E:/Codex/work/job-fastapi`。E 盘不可用时会停止，不改存 C 盘。`start.ps1 -RuntimeRoot` 可显式指定其他位置；批处理入口使用默认 E 盘位置。

服务由单个 Uvicorn 进程启动，勿开启多 worker 或自动重载。启动器先占用公共端口，端口被占用时不重复启动 Node.js。桌面应用继续连接 8788，无须改变界面地址。

## 数据、断点与失败处理

原岗位知识库、分类器目录、语义标签、助手快照、会话及浏览器资料使用现有路径。生产配置和采集运行目录不复制到 API 虚拟环境。

新增 `JOB_API_RUNTIME/operations.sqlite` 保存操作凭据和计算状态，默认位于 E 盘。计算标准输出、错误输出和执行进程日志也保存在该目录。原分析日志仍由业务模块持续更新。

训练、标注、聚类和分析启动请求支持 `Idempotency-Key`。相同标识与内容只提交一次；已收到的确认结果会直接复用。连接异常导致结果不明时返回待核状态，不自动重发付费操作。原有业务接口仍会校验任务状态、授权和预算。

服务重启后，未结束计算记录标记为 `interrupted`，未确认的操作标记为 `uncertain`。不会自动重跑。付费标注继续使用原任务的固定样本、累计费用及断点恢复机制，需用户在界面明确继续。运行中的计算或采集应先停止再重启服务。

Windows 使用 Job Object 管理执行进程、计算子进程和报告处理进程，公共服务退出时一并结束，避免残留后台继续写入。

## 检查与回退

- 工作台：`http://127.0.0.1:8788`
- 接口说明：`http://127.0.0.1:8788/docs`
- 健康状态：`GET /api/backend/health`
- 最近计算记录：`GET /api/backend/jobs`

接口说明列出已迁移契约及常用查询，未逐一列出所有兼容业务接口。助手支持原 SSE 事件流，兼容接口继续保留原路径。

回退前先确认没有采集、标注、分析、浏览器求职或助手回答任务，再停止整个 FastAPI 进程树，确认 8788 和原执行进程已退出。在项目根目录运行：

```powershell
$env:JOB_UI_START_WORKER='0'
$env:JOB_UI_OPEN_BROWSER='0'
node job_collector_ui/server.mjs 8788
```

回退无需转换数据库或删除新日志。不要在 FastAPI 仍运行时并行启动旧服务。
