## 本次变更

采集中心强制 `direct_http_json_only`：不启动、连接或操作招聘网站浏览器，不使用网站页面内的 Vue 客户端代发请求，不回退 HTML/RPA。助手创建任务、控制台入口、调度器、并发协调器和受管理浏览器启动器均执行限制。AI 标注平台不属于本次招聘采集迁移范围。

旧日志的“可提交内存不足”是本机资源保护，不是远端服务器过载。直接 HTTP 可以减少浏览器占用，但不保证任务总内存永远充足；2GB 可提交内存和物理内存保护未降低。

## 请求频率和异常保护

- `work/polite_http_client.mjs` 按精确 HTTPS origin/path 白名单发请求；禁止自动跟随重定向。
- 同站最大并发1，跨任务和跨子进程共享锁、请求时间与冷却状态。间隔下限2500毫秒，配置可更慢，另加抖动；不同来源最多2个平台并发。
- 网络/5xx最多尝试2次，重试仍经过同站节流；401/403/429不自动重试，至少冷却15分钟，尊重更长的 Retry-After（上限24小时）。
- 非 JSON、无效 JSON或已识别的业务验证码停止并冷却；不运行返回脚本，不打开浏览器。响应体上限4MiB。
- 共享状态位于 `ui_data/http_rate_limits/`，仅存站点、时间与状态，不存 Cookie、请求参数或响应正文；启动异常或状态损坏不绕过限速。

## 数据与调度

原任务平台选择、原生数据库和断点不删除；状态 API 额外返回 `availablePlatforms`、`pausedPlatforms` 和 `collectionTransportPolicy`，界面显示暂停原因。新任务禁止选择未开放的渠道；助手工具默认只提供已接入渠道。旧任务续采只派发可用渠道，相关词扩展沿用保守字典，不擅自扩大城市范围。全国查询不冒称按北京筛选。

仅升级请求策略，不重置分页上限、条数预算和断点。无可用直连渠道时明确停止，不将暂停平台记为已采完。可继续使用历史数据做洞察或下载。
