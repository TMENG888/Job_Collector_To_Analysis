# 求职助手消息操作

2026-10-15：沿用现有设计系统颜色，增加聊天消息操作。

## 交互约定

- 提问：复制、编辑。编辑将原提问回填输入框，确认发送后追加新消息；不改写历史，不重放后续操作。取消编辑恢复之前的草稿。
- 回答：复制可阅读纯文本、复制原始 Markdown、重新提问。重新提问也只回填输入框，必须手动发送。
- 代码：每个代码块有独立复制按钮，只复制代码原文，不包含工具条。
- 采集确认／取消回执：只提供复制，不提供编辑或重新提问。既有写操作仍须确认卡片。
- 历史恢复：重新安装操作按钮；过期简历附件不会因编辑而重新上传。
- 长对话：用户上滚时不强制拉回底部，提供“回到最新”。
- 复制失败：安全剪贴板不可用时尝试本机复制降级；两者均失败则提示手工复制，不显示成功。

## 参考边界

用户提供的 DeepSeek 分享链接在当前浏览器跳转到登录页，因此未观察到其登录后界面，也未提取或复用其源码、私有接口、品牌资产。本次是常见聊天交互的独立实现，不声称还原 DeepSeek 内部实现。REA 未连接，本轮使用普通浏览器观察和本项目源码完成工作，未更改 REA 配置。

## 隔离验收

运行 `node work/test_assistant_ui_server.mjs`，访问：

- `http://127.0.0.1:8794/tests/assistant-actions.html`：消息操作回归。
- `http://127.0.0.1:8794/tests/assistant-markdown.html`：原 Markdown 安全与排版回归。
- `http://127.0.0.1:8794/?view=assistant`：固定历史会话，可验证编辑、取消、追加发送、会话切换。
- `http://127.0.0.1:8794/tests/assistant-mobile.html`：390px iframe 视口验收。
- `http://127.0.0.1:8794/api/test/counters`：隔离发送计数，禁止真实工具写操作。

测试服务器不读取生产数据库、简历、密钥或会话，不调用模型或采集接口。生产前端为静态文件，刷新加载即可，无须重启采集服务。
