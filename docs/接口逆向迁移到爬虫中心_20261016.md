# 接口逆向成果迁移到爬虫中心（取代 RPA）— 2026-10-16

## 目标
将 7 个平台逆向出的 HTTP 接口采集能力统一迁移到爬虫中心控制台，取代原 RPA（页面自动化）采集。

## 迁移后的统一架构

**唯一采集入口**：`work/collect_public_job_platforms.mjs`
- 控制台的 `collection` / `public` / `zhaopin` 阶段全部指向它（`job_collector_ui/server.mjs` → `stageCommand`）
- 不再启动 `collect_parallel_channels.mjs` 的独立智联 worker，也不再走 `collect_hybrid_channels.mjs` 的页面 RPA

**7 渠道采集方式**：

| 渠道 | 方式 | 入口函数 |
|---|---|---|
| 智联招聘 | 会话直连（本人登录 cookie，深翻页 ~1000条/城市） | `collectZhaopin` → `direct_zhaopin_session.mjs` |
| 就业在线 | 纯 HTTP 直连（SM 加密，关键词×城市） | `collectJobonlineHttp` → `direct_jobonline_adapter.mjs` |
| 猎聘 | 会话模板 HTTP 直连（人工过一次 IP 验证） | `collectLiepinLimited` → `direct_liepin_adapter.mjs` |
| 前程无忧 | 会话代理（受管浏览器提供 WAF 会话，调用网站接口） | `collect51job` → `job51/collector.mjs` |
| 国聘 | 公开 HTTP 直连（page 翻页） | `collectIguopin` |
| 公共招聘网 | 公开 HTTP（SSR 内嵌 JSON，pageNo 翻页） | `collectMohrss` |
| 实习僧 | 公开 HTTP 直连（page 翻页 + 详情） | `collectShixiseng` |

## 关键改动

### 1. 统一入口（server.mjs）
```js
if (['collection','zhaopin','public'].includes(stage)) return {
  command: process.execPath,
  args: [path.join(root,'work','collect_public_job_platforms.mjs'), task.publicConfigPath, task.outputDir],
};
```
所有采集阶段走同一脚本；RPA 阶段（yupao/boss）保持停用。

### 2. 停用独立智联 worker（collect_parallel_channels.mjs）
- 智联已并入 public；若仅请求 zhaopin，自动转为 public。
- 移除 zhaopin 独立 worker 与低收益补采分支。

### 3. 会话代理平台（取代 RPA 的浏览器部分）
`work/channel_acquisition.mjs` 新增：
```js
export const sessionProxyPlatforms = Object.freeze(['job51']);
```
- 这类渠道**本质是调用网站接口**（非页面 DOM 抓取），仅需本地浏览器提供 WAF/会话。
- `managed_browser.assertBrowserPlatform` 对会话代理平台**任何模式都允许**启动受管浏览器。
- `channel_availability.collectionChannelAvailable` 对其始终返回可用。

### 4. 智联/猎聘用会话直连配置
- 智联：`publicConfig.platforms.zhaopin`（会话城市 48 个）；会话来自 `ui_data/zhaopin_login/cookies.json`
- 猎聘：会话模板 `ui_data/liepin_login/session_template.json`（cookie + xsrf + ckId）

|---|---:|

| 智联 | 78 |

## 使用前提（人工一次性）

| 渠道 | 前置操作 |
|---|---|
| 智联 | `node work/zhaopin_login_helper.mjs`（登录一次，cookie ~1周） |
| 猎聘 | `node work/liepin_captcha_helper.mjs`（过一次 IP 验证，模板 ~30分钟） |
| 前程无忧 | `node work/job51_session_helper.mjs` + `node work/clear_channel_block.mjs job51 --confirm` |
| 国聘/公共招聘网/实习僧/就业在线 | 无需前置（公开直连） |
