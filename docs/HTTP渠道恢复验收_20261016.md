## 实现与保护

1. 策略名改为 `direct_http_validated_data`。HTML自动回退仍关闭，仅精确白名单内的公共招聘网页面可返回已校验内嵌数据。
2. JSON API 按合法正文和渠道字段契约校验，兼容错误MIME；HTML挑战、非JSON和业务验证仍停止。HTTP公共页面禁止携带账户凭据，禁止重定向和脚本执行。
3. 智联新独立worker：`work/collect_direct_zhaopin.mjs`；普通字段契约与规范化在 `work/direct_zhaopin_adapter.mjs`。只读导入归属正确的历史记录，新断点目录 `断点数据/智联招聘_HTTP`，不沿用旧浏览器页码作为已验证证明。
4. 智联页数为绝对最高页码，行数按不同ID计；截断页保留 `next_card_index`。重复页停止当前条件，不假报穷尽。默认每条件3页，配置更低时不扩张；正常资源保护保留。
5. 队列识别新断点、分页/行预算与条件级停滞；相关关键词同步覆盖公开配置和智联配置，保留城市、限额与任务归属。
6. 所有招聘key的浏览器入口独立禁止，HTTP可用标记不会重新开放招聘登录UI或旧浏览器路径；AI标注平台不受影响。
7. 全部请求共享原生产目录 `ui_data/http_rate_limits`，包括隔离真实验收。跨任务/进程同源串行、至少2.5秒（验收4秒+抖动）、最多2次尝试（验收1次）、4MiB上限、20秒超时；401/403/429至少冷却15分钟。
8. 修复拒绝响应体损坏可能触发重试的边界；每次尝试前重新检查冷却。有效SSR中的“人机验证”岗位内容不再误判成挑战页面，但缺失/无效数据契约仍停止。
