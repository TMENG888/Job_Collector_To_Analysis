# 岗位工作台桌面预览

桌面版复用本机服务，提供采集任务、岗位洞察、求职助手三个页面。求职浏览器、内嵌招聘网页、简历求职插件及其桌面操作接口已移除；历史文件和网站登录资料未删除。平台采集及人工登录属于独立采集链路。

先启动本机 127.0.0.1:8788 服务，再双击本目录的 `打开岗位工作台.cmd`。依赖、缓存和桌面运行资料位于 E:\Codex\work\20261019-job-desktop，日志默认位于 E:\Codex\outputs\20261019-job-desktop。已有实例需要关闭后重新打开以加载桌面代码。

本地文件壳与 HTTP 工作台使用独立 WebContents。仅文件壳主框架可以调用状态读取、切换本地工作区这两个固定 IPC。Node 集成关闭，sandbox、contextIsolation、webSecurity 保持启用。

缩放支持 Ctrl＋滚轮、Ctrl＋加减号（含数字键盘）和“查看”菜单；Ctrl＋0 恢复 100%。范围为 50%–200%，顶部导航与业务页面同步缩放，缩放比例保存在 E 盘桌面运行目录，刷新、切换页面和重新打开后保留。
