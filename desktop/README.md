## 第一版范围

- 采集任务、岗位洞察、求职助手复用本地 Web 界面。
- 原生招聘网页、最多8个标签、前进后退、刷新/停止；每个平台独立持久会话。
- 读取当前完整岗位详情、整理当前页可见岗位；复用现有页面解析器。
- 读取已发布/已启用的 TF-IDF＋逻辑回归分类器，仅在用户点击后本地推理。不训练、不付费调用、不改模型激活状态。
- 原生页面已接入简历求职插件，见下方使用说明；普通浏览器扩展保持原通道。

原生嵌入不等同普通 Chrome。BOSS 等站点可能限制 Electron 或要求验证，不能保证兼容、更不绕过风控。失败不自动重载，也不主动导航到空白页；网站自行打开about:blank时，显示明确错误和手动返回入口，不伪装成功。外域登录弹窗、下载、设备权限第一版不支持，不要为此关闭网页安全功能。

## 安全边界

本地文件壳、HTTP工作台、招聘网页为不同 WebContents。只有精确本地文件壳的主框架能调用固定 IPC。招聘网页无 Node、无 preload、无通用代码执行桥；开启 sandbox、contextIsolation、webSecurity。主导航只允许已接入 HTTPS 域名，网页对子资源的本机/私网IP访问被阻止，权限和下载默认拒绝。不修改 UA、不使用反检测标志、不启用远程调试。页面读取代码固定在主进程中；网页内容只按文本显示。

## 原生简历求职插件（2026-10-19）

1. 在桌面「求职浏览器」右侧上传3MB以内、1–6页可解析文字的原版式PDF。DOCX须自行另存PDF；不重新排版、不OCR。简历只在内存，闲置30分钟、清除或关闭App后失效。
2. 逐页预览截图并勾选确认。勾选模型共享授权后，生成3–5个相关搜索词与已有监督模型的对应关系。复用求职助手的DeepSeek配置，不使用Qwen标注密钥；没有适用模型时停止，不回退纯规则。
3. 先点「仅匹配预览」：AI从此轮已训练且已启用的模型目录中自行选择适用的监督分类器，显示每个搜索词对应的模型和选择依据，模型缺失或版本变化时停止并要求重生成。同一词持续遍历可访问列表/下一页，不均分岗位配额；连续5个独立岗位被分类器明确排除后切换下一个词。待复核、分类纳入但简历低匹配均打断排除序列，重复岗位不重复计数；卡片没有职责必须读完整JD。检索页和详情页独立、复用两标签，保留列表位置；列表明确耗尽也可切词。列表停滞、验证、无法确认分页则停止，不猜测已遍历完。默认本批遍历保护上限100条，可设1–300条，每词最多30次列表页面/滚动读取；达到保护上限停止整批，不据此切词。该保护上限不是沟通人数；本地TF-IDF＋逻辑回归纳入后才请求DeepSeek核对简历与JD。证据覆盖不是人工准确率或录用概率。
4. 自动沟通仅支持BOSS，需要额外明确授权本批范围、人数、间隔与原图发送。至少3组非可选的有效匹配、达到覆盖阈值、没有硬性资格缺口或阻塞问题、正文未截断才进入发送。学历、届次、明确出勤/地点/实习时长等硬性资格未知仍阻止发送；普通核心技能缺口降低覆盖率，不一票否决。JD明确的优先/加分项单列且不计核心覆盖率，普通咨询不阻断，JD未提出的条件不能凭空成为必需资格；结构不明的旧标签/问题保守复核。问候语按DeepSeek选出的原文事实组装，不直接发送未经校验的自由文本。点击「立即沟通」可能触发网站默认招呼或简历发送；随后发送定制招呼和已核对PDF的全部原图，包含原始个人信息。
5. 桌面默认核心证据覆盖阈值为60%（可在50%–100%范围调整）；降低覆盖阈值不降低至少3组有效证据、监督分类纳入、硬性资格及原图确认要求。预览显示与实际发送相同的经原文校验问候语，预览本身不发送。
6. 桌面发送账本每批最多5人，至少间隔60秒，过去24小时最多10次尝试；跨批次/重开App仍生效。账本在桌面runtime/recruiter/delivery；不确定记录不自动清除、不重试。锁文件异常时需要先人工核对发送记录；不得直接清空账本绕过限制。此限制只覆盖使用同一桌面账本的操作，不代表网站账户总频率。

启动按钮最多就地显示一项待处理条件，完整原因可悬停查看；就绪或运行中不重复显示操作指南。即时校验人数、间隔、遍历上限、覆盖阈值与预算。预览运行时显示「停止预览」，不能直接升级为自动沟通；停止后仍须用户单独点击「授权并开始」。更换方案会重置发送授权，状态连接失败时不允许使用旧状态启动。

插件的检索词、发送须知、模型用量和岗位匹配详情默认折叠；PDF页确认显示已核对数/总页数，未勾齐时不能确认。结果明确区分预览草稿、发送待确认和已发送；只有发送链路取得网页确认后才标为已发送，不以打印草稿冒充投递。精简展示不改变后台资格检查或发送授权限制。

岗位结果使用固定高度视口、每页5条和状态筛选；全部记录保留，分页不限制实际遍历。新增记录不会自动跳页，点击「新增N条」才查看末页。定时刷新保留当前页、滚动位置和已展开详情；新批次重置页码及筛选。卡片以文字加颜色区分：灰色非目标、橙色条件未满足、绿色可沟通、蓝色已发送、紫色待复核、青色处理中、红色异常/停止。状态数量在筛选器中展示；这些展示分类不改变后端监督分类结果或发送资格。

网站操作在固定隔离world执行，没有网页可调用的IPC、通用脚本入口、UA修改或验证绕过。切换标签/工作区、验证/登录异常、JD/HR身份变化或网页未确认发送时停止。已发生的发送不能由「停止」撤回。平台DOM变更可能导致保守停止，隔离测试不代表实站发送兼容性已验收，更不能保证不被网站限流。

Token按API返回记录，失败且用量不明另计；预算按输入4/输出8元每百万Token的明确假设预留，不是官方价格或实际账单，未计缓存折扣。生成检索方案和执行匹配各自使用面板预算，不是合并总预算；不自动重试付费请求。原始密钥、简历、JD、截图不写模型账本；账本仅保存计数与估算，发送账本保存岗位/收件人哈希及状态。

桌面内的HTTP工作台有一个隔离的布局适配preload：只隐藏原Web侧栏、回收网格宽度，并将固定的4类当前视图状态同步给宿主；不向网页公开Node或通用桌面命令。普通浏览器加载同一服务时不注入适配层，原Web导航保持不变。桌面顶部「求职浏览器」统一进入原生视图，不再显示旧镜像工作区。

## 更新与验证

界面/业务后端保持原更新方式；桌面壳源文件更新后重新打开 App 即可，不需要重新安装 Electron。更换 Electron 版本时更新 package.json 并在新的 E 盘 RuntimeRoot 安装后验证。不要覆盖会话目录；正式发布前再接入签名安装包与可回退的升级机制。本版不是签名安装程序，没有自动更新。

```powershell

.\start.ps1 -SelfTest
```

SelfTest 使用独立测试会话，截获所有招聘域名请求并返回本机夹具，不访问招聘网站、不登录、不发送、不调用付费模型。验证真实 Electron/WebContentsView、原生点击/滚动/中文文本输入、标签切换、隔离、安全策略和插件解析；这不等于真实 BOSS 登录及中文输入法候选窗口已验收。
