# 岗位采集与分析系统 · 本机开发源码

2026-10-29：岗位洞察改为直接分析全岗位知识库，恢复专用 TF-IDF＋逻辑回归筛选，并整合岗位训练、联合语义标注与词云展示。

- 已有分类器：选择目标岗位后生成全量分析，无需选择采集任务数据集。未达发布门槛的候选可用于明确标记的试分析，不自动替换已发布模型。
- 新岗位：输入岗位名称，由 DeepSeek 扩展检索词和起草标注规范，再从全库分层选样，由 Qwen 同时标注岗位类别、技术、职责、业务和行业，最后在本机训练评测。另提供本地聚类发现岗位方向的入口。
- 词云复用联合标注中有原文证据的语义标签；“扩大词云样本”按需展开，只补充缺失或需升级的标签。补充失败时保留已有联合标签预览。
- 采集展示区分岗位入库与面经数据，补充断点分页核验、逐页入库及渠道会话恢复；助手支持气泡内编辑，并完善岗位咨询和薪资样本展示。

分类评测中的精确率、召回率及 F1 表示留出样本与 Qwen 标签的一致性，不等于全库人工准确率。付费标注与提取需在界面确认授权及预算；本地训练和已有标签复用不重复调用模型。
